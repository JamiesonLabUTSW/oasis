# MAPLES public-tour media

These seven posters were captured from the production MAPLES React interface
at OASIS commit `90031150529bbfa1a3de4f5769039fb91940ed08`. The interface was
served with a deterministic, same-origin loopback API fixture; the live MAPLES
stack and grading pipeline were not used.

The Perfume Making → Candle Making narrative is a fresh reconstruction inspired
by Minhan Park and Licheng Yi's public
[walkthrough](https://ut-real-ai-project-maples.com/wayfinder-rubric-authoring-demo)
and [video](https://www.youtube.com/watch?v=MKwseFKuFLs). Rubric wording, notes,
scores, rationales, progress, and review states were newly authored for this
tour. They do not reproduce the interns' original prompts, outputs, data,
runtime, or exact demo.

Only coded records `DEMO-001`, `DEMO-002`, and `DEMO-003` appear. The capture
contains no real learner, student, patient, or other person data. Provider
calls, external network clients, and spend were all zero. The displayed scores
are fixture values, not model outputs.

[`manifest.json`](manifest.json) records the ordered asset inventory, source
identity, byte and SHA-256 checks, static-WebP contract, zero-provider boundary,
and DOM/OCR/manual privacy review. Replace these files only by regenerating the
complete pack and satisfying `scripts/check-site.py`.
