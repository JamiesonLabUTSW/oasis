# OASIS visual assets

The repository retains lossless masters as well as the smaller delivery files
used by the website:

- `oasis-logo-master.png` is the lossless 654×436 OASIS oasis logo preserved
  from the original project site. `oasis-logo.webp`, `oasis-logo-nav.webp`, and
  `oasis-favicon.png` are optimized derivatives for the page, navigation, and
  browser icon.
- `oasis-tui-tour-master.png` is the lossless 1731×909 source artwork for the
  CLI & TUI tour social card. `oasis-tui-tour-social.jpg` is its optimized
  1200×630 delivery derivative, used as the CLI & TUI page hero and social
  preview.

The tour artwork was generated for this release with this prompt:

> Create a polished 1200×630 social preview card for OASIS. Show a dusk desert
> oasis fused with a terminal interface in crisp pixel-art style. Include only
> the exact text “OASIS” and “Explore the CLI & TUI”. Use a navy, sand, gold,
> teal, and coral palette. Do not add other text, data, logos, or watermarks.

Every published visual asset, including these masters, is covered by the
generated `SHA256SUMS` inventory. The brand and demo assets are also
inventoried in `publication.json`.
